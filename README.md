# SpeedVideoJoiner

"SpeedVideoJoiner" программа для объединения и изменение скорости видеофайлов с возможностью перекодировки.

Что умеет:
1. Объединять видеофайлы ('.mp4', '.ts', '.mov', '.avi', '.mkv', '.lrf', '.osv') с одним расширением (первое найденое расширение) из папок/списка файлов.
2. Объединять 360° видео в один файл (без возможности изменить ускорение и перекодировать). Необработанные в "DJI Studio" файлы с расширением '.lrf', '.osv' объединяються не как 360° видео, а сферами.
3. Сортировать файлы "По возрастанию" наименований, по "Порядковый номер" (значения после "_", пример файла: 20260504064828_055834, порядковый номер из него - 055834) и заканчивать обработку по конечный обрабатываемый номер.
4. При опции "Порядковый номер", в случае успешного завершения обработки, "Последний обработаный номер" автоматически заполняется. Так же можно указать дублирование "Последний обработаный номер" в исходную папку (создаёт txt файл с которого будет считываться значение при следующем запуске приложения).
5. Ускорять выходное видео в "N" раз.
6. Исключать звук из видео.
7. Перекодировать выходное видео, с возможностью указать: кодек, FPS, качество, пресет.

Для работы программы необходим установленный "FFmpeg", для обработки 360° видео - "MP4Box".

P.S. Большая часть кода написанна с помощью вайб-кодинга.
